# PageTurner Web

웹소설을 찾아 원문을 불러오고, 번역을 실행해 페이지 단위로 읽고, 이 브라우저에 보관하는
React/TypeScript 클라이언트입니다. 앱에서 저장한 번역본도 같은 서버 서재에서 읽습니다.
서버와 Android 앱의 빌드에 의존하지 않는 별도 npm 프로젝트입니다.

## 실행

Node.js 20.19 이상(20.x) 또는 22.12 이상을 사용합니다.

```powershell
cd web
npm ci
npm run dev
```

기본 주소는 `http://127.0.0.1:5173`입니다. 개발 서버의 `/api` 요청은
`http://127.0.0.1:8080`으로 전달됩니다. 서버 포트가 다르면 실행 전에
`$env:PAGETUNER_WEB_API_TARGET='http://127.0.0.1:18080'`을 설정합니다.
백엔드 준비는 [서버 안내](../server/README.md)를 따릅니다. 연결 화면에서 계정을 만들거나
기존 계정으로 로그인합니다. 개발 서버의 초기 계정은 `PAGETUNER_LOCAL_USER`와
`PAGETUNER_LOCAL_PASSWORD`를 사용합니다.
서버 없이도 첫 화면의 **미리보기 읽기**로 리더를 확인할 수 있습니다.

## 검증과 빌드

```powershell
npm run verify
```

공통 OpenAPI와 생성 타입의 일치 검사, TypeScript 검사, 프로덕션 빌드,
API 무결성·오류·IndexedDB 저장 테스트를 실행합니다.
브라우저 통합 검증 결과는 [웹 프론트 검증 기록](../docs/WEB_FRONTEND_VALIDATION.md)에 있습니다.
계약을 수정한 뒤에는 `npm run generate:api`로 `src/generated/api.ts`와
`src/generated/workflow.ts`, `src/generated/accounts.ts`를 함께 갱신합니다.
`npm run check:api`는 세 생성 파일의 차이를 검사합니다.
기준 계약은 [번역 저장·조회](../contracts/translation-v1.openapi.json)와
[웹소설·번역 작업](../contracts/workflow-v1.openapi.json),
[계정·언어 설정](../contracts/accounts-v1.openapi.json)입니다.
기존 번역 계약은
서버·앱과 동일한 [JSON fixtures](../contracts/fixtures/translation-v1)를 테스트에 사용합니다.
미리보기 본문은 `fixtures/preview-source.json`, 재생성은
`node scripts/generate-preview.mjs`입니다.

프론트 산출물 `dist/`는 `/` 경로에서 서비스합니다. `/api`를 같은 서버로 연결해야 합니다.
Spring Boot JAR에 포함하려면 루트에서 다음을 실행합니다(JDK 21 필요).

```powershell
.\gradlew.bat -PbuildTarget=server -PwebDistDir=web/dist :server:bootJar
```

`-PwebDistDir` 없이 서버를 빌드하면 API 서버만 생성합니다. 웹 npm 빌드가 Gradle에서
자동 실행되지는 않습니다. 개발용 Vite에서는 service worker가 꺼져 있으므로,
**오프라인 새로고침 검증은 프로덕션 빌드**를 사용합니다.

## 사용 흐름과 저장 범위

- **웹소설:** 사이트 선택·검색 또는 책 주소 입력 → 목차 → 회차 선택으로 원문을 서버에 보관합니다.
  **보관 원문**은 요약 목록만 가져오며, 선택한 회차의 본문을 별도로 조회합니다.
  WTR·NovelBuddy는 서버가 제공한 장르·연재 상태·정렬 옵션을 **필터**에서 선택합니다.
  책 소개에서 **즐겨찾기 추가**를 누르거나 **즐겨찾기 → 소스 주소 추가**로 자주 여는 목록을 저장합니다.
- **번역:** 원문 리더의 **번역하기**에서 번역기와 언어를 선택합니다. Google 웹 번역이 기본입니다.
  필요한 API 키는 **연결 설정**에 입력합니다. 서버가 허용한 LLM 주소와 모델만 사용할 수 있습니다.
  **용어집**에서 책별로 최대 200개 용어를 편집하거나 JSON 파일을 가져오고 내보냅니다.
  원문 용어의 대소문자 중복을 거부하고 서버와 같은 fingerprint를 계산합니다. 다음 번역 요청에
  저장한 용어를 실제 포함하며, 재시도는 원래 작업의 용어집을 그대로 사용합니다.
- **번역 작업:** 문단별 진행 상황을 확인하고 취소할 수 있습니다. 다른 화면으로 이동해도 서버 작업은
  계속됩니다. 실패·취소·서버 재시작으로 중단된 작업은 저장된 언어·모델·주소·용어집을 복원해
  완료된 문단부터 재시도합니다. API 키는 다시 입력하며, 완료 후 번역문을 읽거나 기기에 보관합니다.
- **묶음 작업:** 책 목차의 **여러 회차**에서 최대 20회차를 선택하고 원문만 가져오거나 같은 설정으로
  번역합니다. 계정별 기기 checkpoint를 저장하며 일시정지·재개·실패 회차 재시도·남은 작업 취소를 지원합니다.
  재방문 후 **묶음 작업**에서 직접 재개합니다. 이미 서버에 제출한 번역은 창을 닫아도 계속될 수 있습니다.
- **서버 서재:** 연결 후 사용자 소유 번역 목록을 12개씩 받아 화면 높이에 맞게 나눕니다.
  각 revision을 별도 항목으로 표시하며, 책을 열 때 본문을 조회합니다. 서버가 제목을 제공하면
  안정적인 내부 식별자 대신 책·회차 제목을 표시합니다. 기존 제목 없는 번역본도 읽을 수 있습니다.
- **리더:** DOM 크기로 페이지를 계산합니다. 이전/다음, 방향키, Page Up/Down,
  Space로 넘기며 글자 크기를 바꿔도 문단 ID·문자 위치를 기준으로 이어 읽습니다.
  **독서 설정**에서 글꼴·행간·여백·페이지 키·터치 방향을 계정별로 기기에 저장합니다.
  목록은 기본 페이지 방식이며 사용자가 선택하면 터치 스크롤을 사용합니다. 본문은 페이지 방식을 유지합니다.
  **본문 검색** 결과는 문단·문자 위치로 이동하며, 북마크·메모·전체 화면을 지원합니다.
- **이 기기 보관:** 다운로드 시 원본 ID와 SHA-256 해시를 검증한 뒤 IndexedDB에 저장합니다.
  읽기 위치도 기기에 저장합니다. 삭제는 현재 브라우저의 사본에만 적용됩니다.
  **원문 보관**은 리더에서 명시적으로 보관한 원문, **로컬 파일**은 TXT·Markdown·EPUB·PDF를 엽니다.
  로컬 파일 가져오기는 서버 전송 없이 처리합니다. 리더의 **서버에서 번역**은 추출한 텍스트를
  `/api/v1/chapters/upload`에 보관한 뒤 같은 번역 설정 화면으로 이어집니다.
  파일 바이너리·삽화·북마크·메모는 이 업로드에 포함하지 않습니다. 이미지 PDF는 원본으로 읽고,
  텍스트가 있는 페이지만 번역할 수 있습니다. 번역 입력은 최대 10,000문단·100만자입니다.
  PDF 추출에 실패한 페이지는 이미지 페이지와 구분해 표시하며, 일부 텍스트가 빠진 채 번역하지 않도록
  파일 전체 번역을 막습니다. 원본 페이지 읽기는 계속 가능합니다.
  로컬 서재에서는 폴더·태그·즐겨찾기로 분류하고 제목·형식·폴더·태그를 검색할 수 있습니다.
- **연결:** 비밀번호와 Basic 헤더는 메모리에만 유지합니다. 새로고침 후 서버 연결은
  다시 입력하며, 기기에 보관한 번역본은 계정 이름으로 다시 열 수 있습니다.

웹소설 메뉴의 **JSON 카탈로그**에서 PageTurner v0 카탈로그 주소를 입력하면 목록을 검색하고
TXT·Markdown·EPUB·PDF를 기기 서재에 가져올 수 있습니다. 공개 HTTPS와 32MB 한도를 적용하며
카탈로그에 제공된 크기·SHA-256을 검사합니다. 가져온 파일은 읽기와 기존 서버 번역 흐름으로 이어집니다.
소스 카탈로그·책 소개의 제목과 설명은 본문 번역과 별도 작업으로 번역할 수 있습니다.

## 회원가입과 언어팩

연결 화면의 **회원가입**에서 계정 이름·표시 이름·비밀번호를 입력하고 다음 단계에서
화면 언어와 기본 번역 언어를 선택합니다. 가입이 끝나면 자동으로 로그인합니다.
계정 이름은 소문자로 정규화되며, 비밀번호는 공백을 보존합니다.
로그인 후 연결 화면에서 표시 이름과 두 언어 설정을 변경할 수 있습니다.

화면 언어는 한국어·영어 팩을 제공합니다. `ko-*`는 한국어, `en-*`는 영어를 사용하고,
아직 제공되지 않는 유효한 BCP 47 선호(예: `fr`, `pt-BR`)는 계정에 보존하면서 영어로 표시합니다.
**기본 번역 언어**는 다음 번역 작업의 초기값에만 적용하며 이미 실행 중인 작업은 바꾸지 않습니다.

UI 문구는 `src/lib/localeMessages.ts`에 모으고 `translate(key, values)`로 표시합니다.
새 팩은 `registerLanguagePack(tag, messages)`로 등록합니다. UI 타입이나 원문 데이터 모델을
수정할 필요가 없습니다. 원문·번역 본문, 사용자 이름과 책 제목은 인터페이스 언어 변환 대상이 아닙니다.
현재 계정 언어 목록은 서버의 `/api/v1/accounts/languages`가 제공합니다.

## 오프라인 범위

계정 이름은 로컬 사본을 구분하는 표식이며 오프라인 접근을 암호로 보호하지 않습니다.
같은 브라우저 프로필에 접근하는 사람은 저장본을 열 수 있습니다. 브라우저 데이터 삭제,
시크릿 모드 종료 또는 저장 공간 회수로 로컬 사본과 위치가 사라질 수 있습니다.
기기 사이의 읽기 위치 동기화는 이 단계에 포함하지 않습니다.
같은 번역본의 작업 결과·서버 서재·기기 보관함은 문서 ID와 읽기 위치를 공유합니다.
이전 버전의 위치 키와 작업 결과에 남긴 메모는 복구하며 계정 간 기록은 섞지 않습니다.

프로덕션 service worker는 공개 HTML/CSS/JS/아이콘만 버전별로 보관하며 API 응답과
인증 정보는 캐시하지 않습니다. 첫 온라인 방문에서 화면 준비가 완료되고 책 보관이
성공한 뒤 오프라인으로 다시 열 수 있습니다. HTTPS 또는 localhost가 필요합니다.
번역 본문 조회 응답은 최대 4 MiB, 원문·작업 API 응답은 최대 8 MiB이며 초과 응답은 오류를 표시합니다.
한 레코드가 손상돼도 정상 책은 표시하며 손상 항목은 명시적으로 정리할 수 있습니다.
원문과 작업 내역은 서버에 보관하며, 원문·번역문을 명시적으로 기기에 보관하면 오프라인에서 읽습니다.
개인 IndexedDB 저장소는 계정별 원문·즐겨찾기·소스 주소·용어집을 분리하며 본문과 메타데이터 해시를 확인합니다.
즐겨찾기·용어집은 자동 서버 동기화하지 않습니다. 즐겨찾기 목차·새 원문 조회와 번역 실행에는 서버 연결이 필요합니다.
원문 불러오기·번역 시작·취소는 같은 서버의 CSRF 세션과 Basic 인증을 사용합니다.
계정 비밀번호와 번역 API 키는 브라우저 저장소나 서비스 워커에 기록하지 않습니다.

이메일 인증·비밀번호 변경·OAuth와 Drive 업로드는 별도 후속 범위입니다.
