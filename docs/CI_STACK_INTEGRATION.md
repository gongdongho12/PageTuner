  managed worktree에서만 수행한다.
- 기존 `web/`의 계정·소설·표준 ZIP·공유 리더와 PR #5의 `frontend/` Next.js 클라이언트는
  별도 클라이언트다. Next.js의 로컬 백업과 표준 `.ptlibrary.zip`을 같은 형식으로 표시하지 않는다.

  계정 변경 중 네트워크 응답 및 JSON 해석 결과의 폐기를 적용했다.
- 기존 V1~V14 마이그레이션은 수정하지 않고 새 서재 테이블을 V15로 추가했다.
  PR #5 전용 V2를 이미 적용한 DB는 별도 이전 계획이 필요하다. 자동 `clean`/`repair`를 하지 않는다.

  409로 거절한다. 원본 행·해시와 표준 ZIP 경로는 그대로 보존한다.
- Android는 최신 실측 페이지와 canonical 문자 위치를 유지한다. 글꼴 선택은 측정과
  렌더링에 함께 적용하고 기본 내장 글꼴을 유지한다. 번역 메모리는 현재 페이지 ±10으로
  제한하며 다른 문서·언어·저장소의 값을 재사용하지 않는다.
- 중복 카탈로그 선행 요청과 하위 목록 경계에서 상위 카탈로그로 넘어가는 전역 키 폴백을 제거했다.
