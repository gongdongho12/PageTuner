# Android ZIP 읽기 위치 보존

PR #37 이후 미완성 변경을 대조해 발견한 후속 수정이다. 서버 언어별 식별과 웹 위치 보존은 PR #34에 있지만 Android의 ZIP 문자 위치 전달은 원격에 반영되지 않았다. 기존 작업 폴더의 변경은 보존하고 최신 계정 연결 코드와 합쳤다.

ZIP 위치는 원래 문단 ID와 UTF-16 문자 offset이다. Android의 내부 문단 분할 페이지로 열 때 페이지 번호뿐 아니라 페이지 안의 offset도 복원한다. 같은 페이지 안에서 이동한 위치도 저장·재내보내기에 유지한다. 이전 표시 페이지의 끝으로 이동하는 미확정 `fromEnd` 상태는 영속 위치로 저장하지 않는다.

빈 문단의 0, 문단 끝, 분할 경계는 유효하다. 없는 문단·범위 밖 위치·surrogate pair 중간 위치를 첫 페이지나 가까운 문자로 대체하지 않는다. 물리 PDF 페이지와 원문 문자 위치를 변환하지 않는다.

PR #35의 계정 읽기는 별도 서버 reader와 기록 저장소를 계속 사용한다. 계정 읽기의 위치·메모를 ZIP 기기 사본에 쓰지 않으며 연결과 기록 선택 정책을 바꾸지 않는다.

## 검증

- 2026-10-04 최신 PR #37 `74e83cd` 최종 CI 성공을 확인하고 별도 managed worktree에서 기존 계정 연결 코드와 합쳤다. 원래 작업 폴더의 미완성 변경은 그대로 보존했다.
- Android 480개 통과·기존 opt-in 15개 제외(112 suite), APK·lint·계측 소스 컴파일·모듈 경계 성공. lint 오류 0/경고 80/힌트 4. APK 공유 웹 자산 192개·11,018,076 bytes를 빌드 결과와 SHA-256까지 대조했다.
- 원문/번역의 문단 끝·빈 문단 복원 뒤 불필요한 PUT 없음, 잘못된 위치 거절, 실제 ZIP codec→Android 저장소→reader→재내보내기, 같은 페이지 안의 offset 이동을 검사했다.
- 독립 검토에서 오래된 Android 텍스트 페이지 metadata가 웹에서 갱신한 canonical anchor를 덮는 결함을 추가로 발견해 고쳤다. 새 문단 끝 위치를 우선하고 이미지 전용 페이지·북마크는 보존하는 ZIP 왕복 회귀를 추가했다.
- Android 연결 장치는 없었다. 단위 검사·APK 빌드·계측 소스 컴파일은 실제 Android 기기 조작 검증과 구분하며 V3는 계속 미검증이다. S4c와 자산 문서의 실제 서버 연결도 이 수정으로 완료되지 않는다.
