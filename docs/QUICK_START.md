## 파일 읽기와 보관

1. 첫 화면의 **파일 읽기**를 선택한다.
2. **파일 가져오기**에서 TXT·Markdown·EPUB·PDF를 선택한다. 파일당 최대 32 MiB다.
3. **읽기**로 열고 이전/다음 버튼으로 페이지를 넘긴다. 읽기 도구에서 북마크·메모·검색·독서 설정을 이용한다. 이미지 PDF는 페이지 보기만 가능하며 OCR은 후속 작업이다.
4. 나중에 다시 접속해 **파일 읽기**를 선택하면 같은 기기 보관함을 연다. 읽던 위치와 설정은 브라우저 저장소에 보존한다.

계정 없는 보관함과 로그인 계정의 보관함은 분리된다. 로그인만으로 파일·메모를 자동 업로드하거나 합치지 않는다. 브라우저, 프로필, 주소의 포트가 바뀌면 다른 보관함이므로 옮길 때 ZIP을 사용한다. 사이트 데이터를 삭제하면 기기 자료도 사라질 수 있으므로 필요한 책은 ZIP으로 보관한다.

개발 서버는 service worker를 사용하지 않는다. 개발 서버를 끈 뒤 새로고침하는 오프라인 실행까지 이 안내의 검증 범위에 포함하지 않는다. 설치형 오프라인 화면은 [프로덕션 웹 빌드 안내](../web/README.md)를 따른다.

## 책을 일반 파일로 내보내기

웹 첫 화면 **파일 내보내기** 또는 **이 기기 보관 → 파일 내보내기**에서 책을 고른다. TXT·Markdown 형식을 선택한 뒤 **파일 저장**을 누르면 된다. 읽는 중에는 **읽기 도구 → 책 파일 내보내기**에서도 연다. PDF는 원본 PDF 파일을 저장한다. Android는 **Local → ZIP → 책의 파일 내보내기**에서 형식을 고른다.

본문 파일에는 메모·읽기 위치·계정 정보가 포함되지 않는다. 한 회차 문서는 그 회차만 저장하며 EPUB 이미지·원래 레이아웃은 TXT/Markdown에 포함하지 않는다. 원본 PDF 최대 32 MiB, 텍스트 입력 최대 500만 UTF-16 code unit 등의 한도와 [상세 범위·검증](DOCUMENT_FILE_EXPORT.md)을 확인한다. 기록까지 옮길 때는 아래 ZIP을 사용한다.

## 앱 ↔ PC 웹 ZIP 교환

1. 웹 첫 화면의 **ZIP 가져오기** 또는 **이 기기 보관 → 앱 · 웹 ZIP 교환**을 연다.
2. **ZIP 내보내기**에서 기기에 보관된 책을 선택하고 내보낸다. `.ptlibrary.zip` 파일을 PC·휴대폰으로 전달한다.
3. 받는 기기의 ZIP 가져오기에서 파일을 선택하고 목록을 확인한 뒤 **이 기기 보관함에 가져오기**를 누른다. Android 진입점은 **Local → ZIP**이다.
4. 기존 문서와 기록은 덮어쓰지 않는다. ZIP 안의 서버 연결 정보로 자동 동기화를 시작하지 않는다.

규격 v1은 ZIP 32 MiB, 압축 해제 64 MiB, 최대 100문서, 전체 extensions 256 KiB 한도가 있다. 초과 파일은 잘라서 가져오지 않고 거절한다. 계정 없는 파일을 로그인 계정 보관함으로 옮길 때에도 ZIP을 명시적으로 가져온다. 최신 계정 용어집을 포함하려면 별도로 로그인·원본 확인·정확한 연결이 필요하다. 최신 계정 읽던 위치·메모·분류의 전체 ZIP 통합은 남아 있다.

이 실행에서는 `127.0.0.1:8080` 백엔드가 내려가 있었다. 따라서 **현재 열린 미리보기에서 바로 쓸 수 있는 범위는 로컬 파일·ZIP·미리보기 읽기**다. 웹소설·번역·회원가입을 이번 실행에서 실서버로 재검증했다고 주장하지 않는다. 이전에 격리 PostgreSQL/QA 서버 시작이 자동 승인 검토에서 거절된 작업은 우회 실행하지 않았다.

개발 웹의 `/api`는 기본 `http://127.0.0.1:8080`으로 전달한다. 서버 준비는 [서버 실행 안내](../server/README.md)를 따른다. 실제 데이터베이스의 연결 정보를 확인하고 기존 데이터는 보존한다. 서버를 다른 주소로 실행했다면 웹 실행 전에 `PAGETUNER_WEB_API_TARGET`을 설정한다.

## Android APK

이 작업의 debug APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성된다. Android 6.0(API 23) 이상이 대상이다. 직접 빌드하려면 JDK 21과 Android SDK를 준비하고 저장소 루트에서 실행한다.

```powershell
.\gradlew.bat -PbuildTarget=all :app:assembleDebug
```

APK 빌드·단위 테스트·lint·계측 소스 컴파일은 완료했지만 연결된 실기기가 없어 설치 후 SAF/회전/프로세스 재생성/핫스팟/절전 검증은 남았다. 폰 서재 공유 기능의 구현과 물리 비행기·핫스팟 환경 검증을 구분한다.
