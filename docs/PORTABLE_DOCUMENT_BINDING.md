# ZIP 텍스트 문서의 명시적 계정 연결

작업 큐 S4b1. S4a의 원본 확인을 바탕으로, 검증된 텍스트 ZIP 사본을 현재 계정의 서버 기록에 명시적으로 연결한다. PDF·이미지/EPUB 물리 위치와 원본 정보 없는 기기 파일은 S4b2이며, 최신 계정 기록의 ZIP 통합은 S4c다.

## 연결과 읽기

Android와 웹 모두 서버 원본 확인 후 별도 연결 버튼을 제공한다. 연결은 계정·서버 origin·가져온 사본·전체 document identity·서버 record UUID를 기기에 저장한다. ZIP에 연결 정보나 자격 증명을 넣지 않는다. 제목, ZIP checksum, 로컬 book ID나 표시 페이지 번호만으로 연결하지 않는다.

기존 기기 읽기는 네트워크 없이 그대로 사용할 수 있다. 별도 **계정 기록으로 읽기**를 선택하면 전체 문단과 provenance를 다시 검증하고 기존 서버 문서와 같은 canonical reader ID로 연다. Android는 서버 문서를 다시 가져와 전체 identity도 대조한다. 웹은 서버의 전체 identity 확인을 통과한 정확한 ZIP 문단을 사용한다. 계정 위치·메모·분류·용어집은 기존 서버 문서 저장소를 사용하며 가져온 사본의 기록을 복사하거나 삭제하지 않는다.

계정 연결 자체는 로컬 메모·분류·읽던 위치를 서버에 전송하지 않는다. 기존 메모의 최초 bind 업로드나 `migrateDocument`의 이전 기록 삭제를 호출하지 않는다. 계정 기록과 ZIP 기기 기록의 병합·내보내기는 이 작업의 완료 범위가 아니다.

연결 해제는 기기 연결만 지운다. 없는 서버 문서나 불일치가 확인되면 연결을 무효화하고 이유를 표시한다. 네트워크 실패는 연결을 유지하며 로컬 읽기를 제공한다. 계정/client/선택 문서 변경 중 늦은 응답과 취소된 검증은 연결 저장·활성화·삭제를 수행하지 않는다.

## 정확한 위치와 지원 범위

- 순서와 본문이 완전히 일치하는 문단 ID와 UTF-16 offset만 대응한다. 빈 문단의 0과 문단 끝 offset을 보존하고 surrogate pair 내부 offset은 거절한다.
- 서버·앱·웹의 point bookmark/note는 빈 문단과 끝 위치를 허용한다. excerpt는 빈 문자열일 수 있다. 강조는 기존의 비어 있지 않은 정확한 선택 범위 조건을 유지한다.
- 원문 용어집은 사용자가 설정한 번역 대상 언어, 번역본은 실제 targetLanguage를 사용한다. 용어집 계약의 식별자/언어 한도를 만족하지 못하면 연결된 문서의 용어집을 지원한다고 표시하지 않는다.
- PDF·이미지가 있는 ZIP, EPUB 물리 페이지와 텍스트 anchor, 원본 proof가 없는 독립 기기 문서는 연결을 지원하지 않는다. 기존 읽기·파일 교환은 유지하며 가까운 페이지로 임의 이동하지 않는다.

## 검증 근거

- 선행 최신 PR #34의 head `5ddc97f`와 Android CI 성공을 확인하고 `codex/portable-document-binding`에서 시작했다.
- 독립 검토로 비동기 연결 저장/응답 폐기, 오프라인 기기 읽기, 원문 용어집 언어와 문단 끝 메모를 보완했다.
- 격리 PostgreSQL 서버 전체 190개/30 suite 통과. Android 475개 통과/기존 opt-in 15개 제외(112 suite), APK·lint·계측 소스 컴파일 성공. lint 오류 0/경고 80/힌트 4. 웹 428개 통과/1개 제외(59파일), typecheck·API 계약 14개·production/sharing build 성공.
- 실제 독립 8081 서버/임시 DB와 390×844 웹에서 합성 ZIP 가져오기→전체 원본 확인→명시적 연결→계정 읽기를 확인했다. 연결 직후 DB의 위치·메모·분류 행은 각각 0개였다. 계정 읽기에서 만든 새 메모만 서버에 저장됐고, 기기 읽기로 돌아오면 가져온 `기기 메모 보존`/`Only the imported copy.`가 그대로 보였다. 계정 문서 분류 화면도 별도 최초 선택 흐름으로 열렸다. 서버 합성 문서를 삭제한 뒤 계정 읽기는 거절하고 로컬 책·메모는 그대로 읽을 수 있음을 확인했다. 화면 근거는 `.gradle-home/s4b-local-note-preserved.jpg`에 보존했다.
- Android 연결 장치는 없었다. 계측 소스 컴파일과 앱 단위 테스트를 실기기 UI 검증으로 표시하지 않는다. S4b2/S4c와 전체 개발은 아직 미완료다.
