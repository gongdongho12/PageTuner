# 2026-07-11 Release Notes

## Summary

- Activated the Google Web HTML translation provider as the default provider for
  new installs.
- Added safer request/response handling for the Google Web HTML `translateHtml`
  flow without embedding copied browser/session headers.
- Updated Google Web HTML translation so it can run without an API key and only
  sends `X-Goog-Api-Key` when a key is supplied.
- Added local-library organization with per-book folders and category tags.
- Moved imported-book translation cache files under the saved book area:
  `local_library/books/translate/<book-name>.translations.json`.
- Added independent source/target language selector chips while keeping manual
  language-code entry.
- Added manual translation sample files under `examples/translation-samples`.
- Split bundled UI/helper code into focused files for status messages,
  translation language selection, and local-library reader mappers.
