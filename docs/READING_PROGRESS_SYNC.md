# 서버 원문·번역 읽기 위치 동기화

2026-09-16, 에이전트 작업 큐 S1. 계약은 [reading-progress-v1](../contracts/reading-progress-v1.md), 다음 범위는 [작업 큐](AGENT_WORK_QUEUE.md)에 있다.

## 지원 범위

- 같은 서버·계정의 원문 또는 완성 번역 record UUID를 기준으로 문단 ID와 UTF-16 문자 위치를 공유한다. 화면 쪽 번호는 공유하지 않는다.
- 웹 서버 서재, 보관 원문, 서버 문서의 기기 보관본, 원문·번역 보기 전환에 연결했다. 임시 읽기 번역의 명시적 원문 쪽 이동도 원문의 위치를 저장한다.
- Android 서버 서재에서 직접 여는 원문·번역은 서버 문단 ID를 유지하는 문서 매핑을 사용한다. 기기에 TXT 사본으로 내려받은 책, 독립 로컬 파일, ZIP/PDF/EPUB 식별자 매칭은 S4다.
- 북마크·메모·강조·분류·용어집의 자동 동기화는 S2/S3이며 이 API가 처리하지 않는다.

## 보존과 충돌

클라이언트는 변경을 기기에 먼저 저장한다. 웹은 계정별 IndexedDB, Android는 서버·계정·문서별 AtomicFile journal을 사용하며 비밀번호는 저장하지 않는다. 응답이 유실되면 같은 mutation ID와 내용을 재전송한다. 그동안 추가로 이동한 최신 위치는 별도로 보관한다.

서버는 PostgreSQL 트랜잭션에서 예상 version을 비교한다. 다른 기기가 먼저 저장했다면 409와 현재 위치를 반환한다. 앱·웹은 양쪽 위치를 남기고 사용자가 기기 위치 또는 서버 위치를 선택하도록 한다. 마지막으로 읽은 쪽이 더 멀다는 이유로 자동 덮어쓰지 않는다.

열린 계정 세션의 대기열은 리더를 닫아도 다시 처리한다. 로그인 시 기기에 남은 변경도 재개한다. 앱 프로세스/브라우저를 닫은 동안 실행되는 OS 백그라운드 서비스는 아니며, 앱을 다시 열어 서버에 연결해야 한다. 문서 삭제·인증 실패 같은 영구 오류는 새 연결 또는 명시적 재시도까지 자동 요청을 보류한다. 요청 제한은 Retry-After를 존중한다.

페이지 변경과 서버 위치 복원은 구분한다. 웹은 복원 명령의 sequence를 사용하고 이전 구독의 명령을 다시 적용하지 않는다. Android는 사용자 페이지 이동 revision으로 늦은 복원이 사용자 이동을 덮지 않게 한다. 문단 끝 offset과 surrogate pair 경계도 검사한다.

## 실제 검증

- 서버: 격리 PostgreSQL `pagetuner_test_20260915_rolling`에서 전체 99개 테스트 통과. V8 migration, 최초/기존 위치의 동시 CAS, 권한·CSRF·소유권, UTF-16 위치, 응답 유실 재시도, 409, chunked 8 KiB 제한, 요청 제한, 문서 삭제 cascade를 포함한다.
- 웹: 생성된 7개 OpenAPI 계약 일치와 타입 검사·프로덕션 빌드·전체 테스트를 실행했다. 최종 수치는 아래 실행 기록에 남긴다. 영속 대기열, 계정 격리, 다중 탭의 늦은 응답, 빠른 페이지 이동, 최초 GET/IndexedDB 경합, 충돌 양쪽 선택, 429 재연결 보존을 검사한다.
- 브라우저: 실제 localhost 서버·DB와 `web-preview-reader` 개발 계정으로 24문단 검증 원문을 사용했다. 별도 HTTP 클라이언트가 저장한 7번째 문단 복원 → 3쪽 연속 이동 저장 → 다른 클라이언트의 15번째 문단과 충돌 → 서버 위치 선택을 확인했다. 다시 충돌시켜 기기 위치를 선택한 결과도 서버에서 확인했다.
- 문단 끝: 마지막 문단 offset 326을 저장한 뒤 재조회하면 마지막 쪽을 복원했다. 화면 크기가 바뀌어도 위치 복원 자체가 서버 version을 증가시키지 않았다.
- 실제 연결 실패: 미리보기 서버의 활성 작업이 0임을 확인한 뒤 잠시 중지했다. 페이지 이동 중 연결 오류 안내와 양쪽 위치 보존을 확인하고 리더를 닫았다. 서버 재시작 후 리더를 다시 열거나 재시도 버튼을 누르지 않아도 대기 위치 `sync-p24:58`이 version 9로 저장됐다. 미리보기 DB의 기존 원문·번역은 유지했다.
- 기존 91문단 번역문: 20번째 문단 복원, 대응 원문으로 전환할 때 원격의 과거 2번째 문단으로 되돌아가지 않음, 충돌 양쪽 보존, 기기 위치 선택 후 번역문 왕복을 확인했다.
- 재접속 수신: 책을 열어둔 채 네트워크 연결 상태를 전환하고 별도 클라이언트에서 10번째 문단을 저장했다. 연결 복귀 후 책 재열기·수동 확인 없이 24번째 문단에서 10번째 문단으로 자동 복원됐다. 웹은 다시 앱으로 돌아오는 focus에서도 열린 책을 확인한다.
- 화면: 390×844에서 충돌 위치 2개가 동시에 표시됐다. 각 항목 높이 142px, 선택 버튼 44px 이상, 페이지 전체 너비·높이 초과가 없었다. 임시 viewport와 네트워크 테스트 설정은 원복한다.
- Android 실제 장치의 UI/앱↔브라우저 조작은 아직 실행하지 않았다. JVM 테스트·APK 빌드와 실기기 검증을 구분한다.
